    DeletionOperations¶

    Access via client.deletions. Anyone who may request deletion of a record files a request with a reason; platform administrators review it. delete() removes a record directly and is for administrators only.

    request = client.deletions.request(dataset_mfid, reason="Superseded dataset")
client.deletions.get(request["id"])

    delete(resource_mfid, force=False) ¶

    Permanently delete a resource. Admin only.

    By default requires an existing approved deletion request (409 if none). Use force=True to bypass the workflow and hard-delete immediately.

    Parameters:

    Name Type Description Default
    resource_mfid str

    MFID of the dataset or sample to permanently delete.

    		 required
    force bool

    If True, skip the deletion request check and delete immediately.

    		 False

    Returns:

    Name Type Description
    Dict Dict

    {"detail": "Resource {id} permanently deleted"}

    Raises:

    Type Description
    HTTPError 409

    No approved deletion request exists (only when force=False).
    HTTPError 404

    Resource not found.
